## What Koinly Brings to Cryptocurrency Tax Workflows

Koinly is a cryptocurrency tax reporting platform designed to help users organize digital asset transactions and prepare tax-related records. It brings supported wallet and exchange data into a structured workflow for reviewing cryptocurrency activity.

Transaction imports are a central part of the process. Depending on the supported integration, users may import records through an API connection, wallet address, or file upload. The available methods vary by service.

Consolidating records from multiple sources can make portfolio activity easier to review. Users can examine transactions from supported exchanges and wallets in one place rather than assembling every record manually.

Accurate transaction history is essential for useful tax calculations. Missing purchases, duplicate imports, incorrectly categorized transfers, or incomplete historical data can affect calculated results.

Capital gains and losses are typically calculated using transaction values and the applicable cost basis methodology. The correct treatment depends on local tax rules, transaction details, and the settings used for the report.

Koinly provides tools for reviewing imported transaction data. Users should investigate warnings, missing acquisition records, and unexpected balances before relying on the resulting figures.

Tax report generation helps organize information for tax preparation. Available report types and supported calculations depend on the relevant jurisdiction, account plan, and current platform capabilities.

Different countries apply different rules to cryptocurrency activity. Tax treatment may vary for trading, staking, mining, lending, gifts, and other digital asset transactions, so users should select the appropriate jurisdiction and review the applicable requirements.

DeFi activity can involve multiple protocols and transaction types. Where supported, importing and classifying these records can help users maintain a more complete history of digital asset activity.

Wallet and exchange integrations can simplify record collection, but no integration should be assumed to capture every transaction automatically. Users should compare imported records against the original sources and investigate gaps.

Tax preparation integrations may support transferring information into compatible accounting or tax products. Users should verify current compatibility and review exported figures before submitting a return.

Accountants and tax professionals may use organized transaction histories to review client records. Clear documentation of source accounts, transaction classifications, and adjustments can make the review process more efficient.

Historical prices and transaction values are important inputs for calculating gains and losses. When pricing data is unavailable or appears incorrect, users should investigate the affected entry and follow the platform's supported correction process.

A reliable crypto tax workflow should include regular data checks. Reviewing account connections, confirming transaction completeness, and keeping copies of source records can help reduce avoidable errors.

Security also matters when connecting financial accounts. Users should verify permissions, protect account credentials, and never disclose wallet recovery phrases or private keys to untrusted services.

Koinly can assist with organizing tax information, but generated reports do not guarantee compliance with every tax obligation. Users remain responsible for reviewing their records and confirming that the final figures reflect their circumstances and local rules.
